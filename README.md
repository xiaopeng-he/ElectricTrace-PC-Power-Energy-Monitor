# 电迹 · 电脑功耗、温度与耗电量监控

**ElectricTrace — PC Power & Energy Monitor for Windows**

电脑现在消耗多少功率？CPU 和显卡有多热？今天运行下来用了多少电？电迹把这些信息放在一个桌面工具里：用悬浮窗随时看状态，用实时曲线看变化，用历史统计查看耗电量和费用。无需外接设备，记录保存在本机。

## 功能介绍

### 随时了解电脑状态

实时监控页把 CPU 和 GPU 分开展示，优先呈现功率、温度和占用率，并补充频率、内存、显存等信息。下方曲线可切换功率、温度与占用率，悬停查看对应时刻的数值，选择时间范围或统计口径。

| 数据 | 可以查看的内容 |
| --- | --- |
| CPU | 封装功率、温度、占用率、核心频率，以及可用的逐核心传感器 |
| GPU | 功率、温度、占用率、核心频率、显存用量与频率、显存控制器活动 |
| 内存 | 物理内存用量、总量、可用量，系统提交用量与上限 |
| 电池与散热 | 供电状态、电量、放电或充电功率、容量及可用的风扇转速 |
| 使用统计 | 今日与本次耗电、平均功率、有效记录时长、峰值与电费估算 |

### 看清耗电变化

历史记录支持按日、周、月或自选日期查看耗电量和平均功率。可切换 CPU、GPU、部件合计、电池放电等统计口径，并导出 CSV，方便比较不同工作负载或整理自己的使用记录。

历史页会显示本机已有记录的日期范围，点击 **查看已有 CPU + GPU 记录** 可直接回到已有实测数据。整机估算从启用后开始保存，较早记录可用 CPU/GPU 口径查看。

电价可以在设置中修改；启用整机估算后，也可以设置其他部件的参考功率。页面会标明当前使用的统计口径。

### 单独测量一段使用过程

在概览点击 **开始测量**，输入可选名称，例如“游戏一小时”或“视频导出”，选择 CPU + GPU、CPU 或 GPU。结束后会保存耗电量、费用、总历时、有效记录时长、平均/峰值功率和 CPU/GPU 最高温度。统计使用开始时选定的口径与电价，方便比较不同设置下的使用情况。

进入 **历史记录 → 任务测量** 可查看保存的结果，顶部日期筛选同样适用。名称描述这段使用过程，电量来自对应硬件读数。关闭软件或意外退出后，已保存的结果保留为“已中断”。

### 记录高温发生的过程

CPU 或 GPU 达到设置中的温度阈值时，电迹自动记录事件的时间、峰值与有效持续时长；温度回落至阈值以下 3°C 时结束。历史页展开 **高温事件** 即可查看。读数中断、软件退出和阈值调整分别标记，托盘弹出提醒仍可单独开关。

两类记录复用已有采样，随本地备份一起保存。每类列表显示所选日期范围内最近 100 条，默认折叠，按需展开。

### 桌面悬浮窗

悬浮窗集中显示主要读数，支持拖动、置顶和返回完整窗口。主窗口关闭后收至托盘，后台继续采样；需要结束记录时，从托盘选择“退出”。

### 登录后在后台记录

支持直接从托盘开始采集，打开统计窗口时再加载完整界面。双击托盘图标或普通快捷方式即可查看，记录使用同一进程继续积累。

0.5.7 起，启动器会在主程序意外退出后尝试恢复后台采集，并保留退出与恢复日志；正常选择“退出”后保持关闭。

要随 Windows 登录启动：复制“电迹”快捷方式，在属性的“目标”末尾加上 ` --background`；按 `Win + R`，输入 `shell:startup`，把这个快捷方式放进去。希望同时开启 CPU 增强采集时，再加 ` --cpu`。安装版可先从托盘右键 **CPU 登录自动采集 → 启用（首次授权）** 完成一次管理员配置，之后启动和重连无需逐次确认。删除启动文件夹中的快捷方式即可取消自动启动。

### 按需查看硬件详情

硬件详情提供 24 项常用指标的统一目录，并标注数据来源。支持关键词搜索、按设备筛选、只看有读数的项目，以及展开原始 CPU 传感器。

![硬件指标搜索与筛选](assets/metrics.png)

*筛选用于整理当前视图，原始记录保持完整。硬件未提供的项目显示“—”，实际测得的零值正常显示。*

另外提供石墨、清透、雾蓝三种主题、采样间隔设置、温度提醒，以及本地备份与还原。隐藏主窗口时释放主页面，悬浮窗使用独立页面，减少后台保留的界面资源。

## 快速上手

1. **安装并启动。** 安装版运行下载的 EXE；便携版完整解压后双击 `电迹.exe`。
2. **开启 CPU 增强采集。** 在应用中读取 CPU 封装功率和温度。安装版托盘右键“CPU 登录自动采集→启用”可完成一次管理员配置，之后自动连接；也可保留逐次确认方式。增强采集使用已有的兼容 PawnIO 驱动；具体准备见[兼容说明](docs/COMPATIBILITY.md#可读取哪些传感器)。
3. **选择你关心的读数。** 日常看实时监控；需要持续关注时打开悬浮窗；查找单项数据时进入硬件详情。
4. **设置电价与采样间隔。** 在设置中填写实际电价。默认每 2 秒记录一次，可在 1–30 秒之间调整。
5. **积累并查看历史。** 运行一段时间后，在历史记录中选择日期和统计口径，查看耗电量或导出 CSV。

## 功率、耗电量和电费怎样理解

| 名称 | 含义 | 示例 |
| --- | --- | --- |
| 功率 · W | 当前消耗电能的速度 | 150 W 表示这一时刻的功率 |
| 电量 · Wh / kWh | 一段时间内累计消耗的电能 | 持续 150 W 运行 2 小时，约为 300 Wh |
| 度电 | 日常电费使用的电量单位 | 1000 Wh = 1 kWh = 1 度电 |
| 电费估算 | 累计电量 × 设置的电价 | 0.3 度 × 0.60 元/度 = 0.18 元 |

**选择统计口径，才能正确理解电量：**

- **CPU + GPU 部件合计**：这两类部件的有效功率之和，屏幕、其他硬件和适配器损耗另计。
- **CPU / GPU**：单个部件的功率与累计电量。
- **电池放电**：笔记本实际放电时的整机直流侧读数。
- **整机估算**：在部件读数上加上你设置的其他部件参考功率，页面标为估算。

电迹按相邻有效采样累计电量。退出、休眠或缺少传感器读数的时段保留为空档；曲线、历史和费用使用相同的数据含义。查看插座侧用电量时，应使用对应的电表读数。

## 数据保存与备份

| 使用方式 | 默认数据位置 |
| --- | --- |
| 安装版 | `%LOCALAPPDATA%\ElectricTrace\data` |
| 便携版 | 软件文件夹内的 `data` |

实际位置可在应用中查看。历史记录、偏好设置和备份均保存在本机，应用无需注册账户。

在 **设置 → 数据与运行** 创建 `.etbackup` 备份，可同时保存已记录的历史与设置，采样继续进行。还原时先校验备份，确认后重启；原文件保留在 `restore-points` 恢复点，便于找回。

每天首次成功记录后，软件会在实际数据目录的 `auto-backups` 中生成一份 `.etbackup`，保留最近 7 份自动备份。可在 **设置 → 数据与运行 → 还原备份** 选择这些文件。手动备份与恢复点独立保留。

已有数据库暂时找不到或无法打开时，软件进入恢复提示，方便检查目录或选择备份。

升级前建议创建一份备份。便携版迁移电脑时，保留完整软件目录和 `data`；安装版卸载会保留数据。历史数据库、CSV 和备份按普通本地文件保存，请按个人资料妥善保管。详见[隐私说明](docs/PRIVACY.md)。

## 常见问题

### 我的电脑该下载哪个包？

Windows x64 和 32 位 x86 都下载同一个安装版或便携版，程序自动选择架构。Windows ARM 的适用范围见[兼容说明](docs/COMPATIBILITY.md)。目前提供 Windows 安装包。

### 为什么有些指标显示“—”？

这表示设备、驱动或当前权限没有提供该项读数。例如，CPU 温度和功率需要增强采集；风扇、电池和部分显卡指标取决于设备。其他可用项目继续记录。

### 为什么曲线会出现空白？

空白表示该时段没有有效读数。先查看页面的采集状态：CPU 增强采集断开时可重新连接；记录暂停时可按提示恢复。重新采样后继续积累，历史空档保留。

### 为什么之前的历史看起来不见了？

先看历史页的“本机已有记录”范围，再检查日期和统计口径。点击“查看已有 CPU + GPU 记录”可直接打开已保存的实测历史。0.5.7 统一了从桌面和隔离工具启动时的数据入口，避免相同路径显示不同记录。

### 关闭窗口后还会记录吗？

会。关闭主窗口会收至托盘，悬浮窗可以独立使用；从托盘选择“退出”后结束采集。

### Windows 提示“未知发布者”怎么办？

当前预览包尚未使用可信代码签名证书。请核对文件来自本项目的 [GitHub Releases](https://github.com/xiaopeng-he/ElectricTrace-PC-Power-Energy-Monitor/releases)，可用 `SHA256SUMS.txt` 检查下载完整性，并保持 Windows 防护开启。
