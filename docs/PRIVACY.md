# 本机数据与隐私

电迹读取硬件型号、时间、功率、温度、使用率、频率、内存/显存及硬件提供的电池信息。程序没有账户、云同步、广告或应用内历史上传流程。正常采样不读取键盘输入、屏幕画面、文档正文或浏览历史。

安装版保存在 `%LOCALAPPDATA%\ElectricTrace\data`；便携版保存在软件自己的 `data`。界面显示实际位置。设置包含电价、主题和窗口偏好；数据库包含采样、电量、你填写的测量名称、测量汇总及高温事件记录。

历史、CSV、`.etbackup` 和恢复点是未加密的本地文件。分享它们会分享设备与使用情况，请用 Windows 账户及文件权限妥善保管。卸载安装版保留数据；需要移除时由你在正常退出后决定如何处理。

完整界面的接口只监听本机随机端口，每次启动使用新的会话凭证。原生宿主附加凭证，网页与网址不保存明文凭证。`session.dat` 由 Windows 当前账户的数据保护功能保护；同一账户运行的程序和更高权限管理员不在隔离防护范围内。

CPU 增强只在用户确认后启动独立提权进程，复用已有兼容驱动，不关闭系统安全防护。Windows、驱动及 WebView2 自身的更新行为由对应组件负责。

故障日志和诊断可能包含设备与文件路径。公开反馈只需提供必要的脱敏错误文字，勿提交完整日志、历史、备份、配置目录或 `session.dat`。界面与文档中的预览图使用示例数据。
